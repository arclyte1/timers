# Вместе — синхронизированные таймеры

Веб-приложение с общими таймерами: создание, редактирование исходной длительности и текущего остатка, запуск, пауза, сброс, удаление и группировка. Изменения синхронизируются между всеми пользователями через WebSocket. Сервер ограничивает пространство 1000 таймерами и 100 группами.

## Запуск в Docker

```bash
docker compose up --build -d
```

Откройте [http://localhost:3000](http://localhost:3000). Данные сохраняются в именованном volume `timer-data` и не теряются при перезапуске контейнера.

Остановка:

```bash
docker compose down
```

Чтобы также удалить сохраненные данные: `docker compose down -v`.

## Локальная разработка

```bash
npm install
npm run dev
```

По умолчанию сервер работает на порту `3000`. Переменные окружения: `PORT` и `DATA_DIR`.
